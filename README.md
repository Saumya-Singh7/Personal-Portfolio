# Portfolio

A simple React and Tailwind CSS portfolio. The home page links to About, Skills, Projects and Contact sections.

## Start the site

```sh
npm install
npm run dev
```

## Make it yours

- Edit your details and projects in `src/data.ts`.
- Put your PNG portrait at `public/profile-photo.png`.
- Edit the hero in `src/components/Hero.tsx`.
- Edit other sections in `src/App.tsx`.
- Use Tailwind classes to change spacing, colors and layout.

Tailwind is installed with the Vite plugin. Its small CSS entry is `src/styles.css`.
